Graphics engine: Isometric 2D use DirectX, Minimal size 800x600 of window in window mode, only Windows OS support.
Game grid: minimum size 15x15, maximum size 30x30, game characters described in Items folder.
Game resources: generate png sprites for each character in post-apocalypse style. 
Gameplay: 
    generate random battle grid, 
    filled 30% of the Wall randomly, 
    allocated two robots as far as posible from each other, 
    each robot can do only one action per turn,
    select with robot start a game the first is randomly.
